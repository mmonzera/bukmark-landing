Bukmark ada di Play Store?

Belum. Untuk sekarang Bukmark dibagikan lewat file APK, jadi kamu install manual di HP Android.

Platform apa saja yang didukung?

TikTok, Instagram, YouTube Shorts, Threads, X, dan LinkedIn. Link dari situs lain juga bisa disimpan sebagai tautan web.

Gimana cara install APK-nya?

Download Bukmark.apk di HP, buka file-nya, izinkan install dari sumber ini kalau diminta, lalu tap Install. Android mungkin menampilkan peringatan keamanan, itu normal untuk aplikasi di luar Play Store.

Gimana cara update ke versi baru?

Download APK terbaru dan install di atas versi lama tanpa uninstall. Bookmark dan koleksimu tetap ada.

Gimana kalau ganti HP?

Buka Profil → Cadangan & Pindah HP → Kirim cadangan. Kirim file-nya ke dirimu sendiri, lalu di HP baru pilih Pulihkan dari file.

Datanya disimpan di mana?

Hanya di HP kamu. Bukmark tidak memakai akun maupun server. Karena itu, cadangkan secara rutin.

Apakah gratis? Bisa di iPhone?

Gratis. Saat ini hanya tersedia untuk Android.
